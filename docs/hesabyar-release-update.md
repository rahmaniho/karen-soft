# به‌روزرسانی سایت برای حساب‌یار اندروید ۱٫۴٫۲

تاریخ بررسی و انتشار: ۱۳ آبان ۱۴۰۵ (2026-11-04)

## هدف و دامنه

درخواست مالک، قرار دادن دانلود مستقیم APK آزمایشی حساب‌یار ۱٫۴٫۲ روی سایت و توضیح
تغییرات آن بر اساس مخزن `rahmaniho/KarenYar` بود. این تغییر لینک دانلود، مشخصات فایل،
یادداشت انتشار، هشدار نصب/پشتیبان‌گیری، متادیتا و راهنماهای مرتبط را به‌روز می‌کند.
قیمت لایسنس، نشانی نسخهٔ وب، مسیرهای موجود و معماری سایت تغییر نکرده‌اند.

## اصلاح متن و تصویر به درخواست مالک

پس از انتشار اولیه، مالک درخواست کرد برچسب فنی «نسخه آزمایشی · Android Debug» و
هشدار طولانی کنار دانلود حذف شود. متن عمومی اکنون فقط این راهنماست:

> قبل از به‌روزرسانی حتماً از اطلاعات خود در برنامه پشتیبان تهیه کنید. اگر برنامه به‌روزرسانی نشد، برنامه را پاک کنید و نسخهٔ جدید دانلودشده را نصب کنید.

این متن در `HESABYAR_UPGRADE_INSTRUCTIONS` نگه‌داری می‌شود و بخش دانلود خانه/محصولات،
صفحهٔ اختصاصی، FAQ و `llms.txt` از آن استفاده می‌کنند. مشخصات فنی انتشار در همین
گزارش داخلی و منبع GitHub باقی می‌ماند، اما در متن عمومی دانلود برچسب Debug/Pre-release
نمایش داده نمی‌شود.

تصویر معرفی و اشتراک‌گذاری نیز با لوگوی رسمی ارسالی مالک جایگزین شد:

- `public/images/hesabyar/hesabyar-cover.jpg` — کاور ۱۵۳۶×۸۶۴ با لوگوی کامل روی زمینهٔ مشکی.
- `public/images/hesabyar/hesabyar-mark.png` — نشان مربعی ۵۱۲×۵۱۲ از همان لوگو برای کارت محصول.
- تصویر قبلی برای مسیرهای قدیمی/کش حذف نشده، اما دیگر در صفحهٔ محصول، بخش دانلود یا
  راهنمای فروشگاه استفاده نمی‌شود.

## حذف ردیف پیوندهای فنی از تغییرات نسخه

مالک سپس درخواست کرد این سه پیوند از بخش `#release-notes` در
`/products/hesabyar` حذف شوند:

- «یادداشت انتشار رسمی در GitHub»
- «دریافت فایل SHA-256»
- «منبع تغییرات همین ساخت»

کل ردیف از `components/site/hesabyar-release.tsx` حذف شد، نه اینکه صرفاً با CSS
پنهان شود. شش کارت تغییرات و لنگر `#release-notes` باقی مانده‌اند. جملهٔ معرفی نیز
دیگر به یادداشت رسمی پیوندنداده ارجاع نمی‌دهد. این حذف فقط مربوط به بخش تغییرات نسخه
است؛ کارت مستقل نسخهٔ اندروید، راهنمای نصب بخش دانلود مشترک، لینک APK، قیمت‌ها،
متادیتا و `llms.txt` تغییر نکرده‌اند. منابع فنی همچنان در همین سند قابل بررسی‌اند.
آزمون مستقل، نبود هر سه پیوند در بخش تغییرات و باقی ماندن کارت‌ها را بررسی می‌کند.

### حد اعتبارسنجی فایل

وضعیت دارایی در API (`uploaded`)، اندازه و digest با یادداشت رسمی مطابقت دارند و
نشانی دقیق APK به پاسخ HTTP 302 گیت‌هاب می‌رسد. دریافت کامل باینری در این محیط به
دلیل محدودیت دسترسی به میزبان امضاشدهٔ دارایی‌های GitHub انجام نشد؛ بنابراین
SHA-256 بالا **مقدار رسمی تأییدشده از API/یادداشت انتشار** است، نه نتیجهٔ hash کردن
یک APK دانلودشده در این محیط. موفقیت ساخت نیز جای آزمون روی دستگاه واقعی را نمی‌گیرد.

## نگهداری انتشار بعدی

منبع واحد: `lib/hesabyar.ts`. برای انتشار بعدی فقط نام فایل را عوض نکنید:

1. انتشار و دارایی را از GitHub API بررسی کنید؛ نوع Debug/Release، اندازه، digest،
   تاریخ، tag و commit منبع را ثبت کنید. تغییرات را از یادداشت همان انتشار بخوانید.
2. ثابت‌های نسخه/لینک/هش/اندازه/تاریخ و `HESABYAR_RELEASE_CHANGES` را به‌روز کنید.
   `HESABYAR_SEO` و `HESABYAR_UPGRADE_INSTRUCTIONS` نیز باید با همان انتشار و متن مصوب مالک سازگار بمانند.
3. بخش دانلود مشترک (`components/sections/hesabyar-download.tsx`) در خانه و محصولات،
   صفحهٔ اختصاصی و `components/site/hesabyar-release.tsx` از منبع واحد می‌خوانند.
   `llms.txt` و lastmod نقشهٔ سایت نیز به‌روز می‌شوند؛ قیمت‌ها را بدون تأیید مالک تغییر ندهید.
4. آزمون‌های `tests/hesabyar*.test.ts` و `tests/e2e/hesabyar-release.spec.ts` را با
   مشخصات واقعی انتشار جدید به‌روز کنید؛ انتظار نسخهٔ قبلی را صرفاً حذف نکنید.
5. دروازه‌های کیفیت زیر را اجرا و سرور production preview را بعد از build بازراه‌اندازی کنید.

```bash
npm ci
npm run typecheck
npm test
npm run build
npm run test:e2e
npm run audit:a11y
npm run audit:a11y:demos
npm run audit:routes
npm run seo:audit
```

در بخش دانلود، پیوند یادداشت تغییرات، فایل SHA-256، FAQ به‌روزرسانی، بارگذاری کاور جدید لوگو
و `og:image`، نبود سرریز افقی در ۳۲۰ پیکسل و axe در حالت روشن/تاریک را پوشش می‌دهد.
اسکرین‌شات بخش دانلود در ۳۲۰ و ۱۴۴۰ پیکسل و صفحهٔ محصول/مقاله بررسی شد؛ سرریز افقی ۰ بود.
ممیزی‌های دسترس‌پذیری ۰ شکست WCAG داشتند؛ همان گزارش گذرای React #418 که پیش‌تر ثبت شده بود
در چند بررسی غیرstrict دیده شد و دروازهٔ axe را قرمز نکرد.
هیچ ادعای استقرار تولید یا تأیید فروشگاه اندروید در این گزارش وجود ندارد.

## راستی‌آزمایی حذف ردیف پیوندها

روی خروجی production همین اصلاح در ۱۳ آبان ۱۴۰۵:

- `npm ci`: موفق، ۰ آسیب‌پذیری؛ typecheck و build موفق.
- `npm test`: ۲۱ فایل / ۱۱۵ آزمون موفق، شامل آزمون مستقل حذف ردیف پیوندها.
- آزمون متمرکز مرورگر حساب‌یار و دیجی‌کارن: ۸/۸ موفق؛ شش آزمون حساب‌یار شامل نبود
  لینک‌های حذف‌شده، دو دکمهٔ دانلود، FAQ و axe در ۳۲۰ پیکسل روشن/تاریک هستند.
- دسترس‌پذیری مسیر `/products/hesabyar`: ۴ بررسی / ۰ شکست / ۰ خطای runtime.
- `audit:routes`: ۹۷ صفحه / ۹۷ canonical / ۱۴۸ مسیر و دارایی؛ موفق.
- `seo:audit`: ۹۷ صفحه / ۰ خطا / ۰ هشدار.
- HTML ساخته‌شده و اسکرین‌شات ۳۲۰ و ۱۴۴۰ پیکسل: شش کارت، صفر لینک در بخش تغییرات،
  هر سه عنوان حذف‌شده غایب و سرریز افقی صفر.

در اجرای کامل محلی، آزمون‌های حساب‌یار موفق بودند؛ یک آزمون موجودِ تغییر مسیر
`/demo/law-office` در مرورگر جایگزین هنگام انتظار برای رویداد load با خطای شبکه
متوقف شد. پاسخ سرور جداگانه بررسی شد: HTTP 308 به `/portfolio` و رسیدن مرورگر به
همان مقصد تأیید شد. هیچ فایل مسیردهی یا آزمون تغییر مسیر در این اصلاح تغییر نکرده
است. نتیجهٔ اجرای کامل CI پس از push در pull request ثبت می‌شود.
